在自己机器上跑

macOS / Linux 都行。只需要 Bun，不起任何服务。

# 装依赖并启动
cd kunpeng-devkit-ai-tui/tui
bun install --frozen-lockfile
bun run dev

# 跳到某个画面
bun src/index.tsx --screen=charts
bun src/index.tsx --screen=components
bun src/index.tsx --screen=patterns

# 质量门禁
bun run check

这是什么

React 19 + OpenTUI 0.5.1 编译的 devkitai 二进制， 在 160×45 真实 PTY 里跑完十幕迁移流程的字符流录像。

录的是字符和 ANSI 转义序列，不是像素——文字可以选中复制， 颜色是原样 24-bit 真彩，放大也不糊。

窗口建议 160×45 以上。窄于 80 列走 narrow 档， Dock 整个隐藏——那是刻意的降级，不是画崩了。

怎么录的

Python pty.fork() 开真 PTY， TIOCSWINSZ 钉死 160×45，脚本注入按键。

按键不按固定秒数发——改成等输出安静下来再发下一个键， 配超时兜底，十幕一次跑通。存成 asciicast v2。
