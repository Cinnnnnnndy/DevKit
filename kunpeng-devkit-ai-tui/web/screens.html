五个典型页面

从《DevKit AI TUI 设计输入》里挑出五屏最吃劲的：启动页（能不能马上开始）、Agent Workspace（Agent 在干什么）、执行中 Tool + Diff（有没有跑偏）、任务结果页（我得到了什么）、管理配置（Agent 到底能不能工作）。五屏刚好把设计输入 §9.1 的六个问题答完 ①②③④⑥，只剩 ⑤ 多任务由 Task Manager 承接。

五屏都是整屏字符帧，不是配色示意图：160 列宽屏 + 80 列窄屏各一帧，每行宽度在生成时被断言把着（tools/screens.py），CJK 按 2 格、Braille 按 1 格算——页面上看到的对齐关系，就是终端里的对齐关系。色值全部取自设计系统的既有色阶，未新造调色板。

Foundation

五屏共用的规则

这些规则不属于任何单屏，写在这里，五屏都遵守；与应用框架一节同源。

① 三条锚点永不隐藏

Header（我在哪 / 连什么机器）、Input（我怎么说话）、Status（现在什么状态）在各屏里位置一致、永不折叠。高度不够时先砍 Console，再砍 Canvas，最后砍 Tab Bar。

② 状态先于内容

每屏左上角第一个非框线字符就是状态符号（● Running / ✓ Completed / ⏸ 待配置 / ⚠ 风险）。用户扫一眼左上角就知道要不要继续读。

③ 结论与证据同屏

屏 2/3/4 都留了证据位：Inspector 的案例库编号、Diff 的“为什么”、结果页的源码行。没有证据位的结论不允许出现在画布上。

④ 数据走色阶，结论走语义色

bar、火焰图、热力走域色阶（o3–o8 / g3–g8）；只有被判定为问题的数值与文字才上 warning / danger。50% 的占比本身不是错误。

⑤ 画不下就显式说

火焰图标 3 帧过窄未显示、热点表标 … 24 more、Console 标 9 行未展开。悄悄省略会把“我看全了”变成错觉。

⑥ 圆角等于浮起

固定区域一律直角 ┌┐└┘；Plan 卡、Tool call、高危确认、错误卡这些浮层才用圆角 ╭╮╰╯。五屏里出现的每一个圆角都是浮层。

Screen 01

启动页 —— 回答“我能不能马上开始”

用户敲完 devkitai 看到的第一屏。它要同时交付四件事：我是谁（Logo + 能力）、环境行不行（本机架构 / 工具链 / 模型连通性）、怎么开口（输入框 + 命令）、能不能接着上次干（最近 Session）。缺任何一件，用户都得多问一轮。

过程可观察（§2.3）

Agent 区固定四行：状态 + Skill + Tools + 进度。任何时刻这四行都能回答“它在做什么、用什么、到哪一步”，不需要展开日志。

执行可控制（§2.4）

Agent 行右端常驻 [Esc] 中断；Plan 卡右上角常驻 [e] 改计划。控制入口和状态显示在同一行，不藏进菜单。

多任务可管理（§2.5）

顶部 Tab + Dock 任务列双重呈现：Tab 管切换，列表管全局状态。⏸ 待配置 同时在底栏常驻提示——它卡着不动且需要人。

上下文可见（§2.6 前置）

Inspector 底部的 ctx 水位是结果质量的先行指标：到 72% 转 warning，到 90% 主动建议 /compact，不等它爆掉再解释。

Agent 执行中 · Tool + Diff —— 回答“它有没有跑偏”

竞品分析里情绪最低点落在“人审查 AI 改动”这一步，没有一个产品做到 hunk 级接受/拒绝。这一屏就是对着那个缺口设计的：左边是执行过程与工具调用，右边是逐 hunk 的代码审查，每个 hunk 都带“为什么”和可跳转的证据。

指纹变化一律拦截

主机指纹与上次不一致时暂停对该机的所有任务并要求重新确认，不提供“永久忽略”。这是唯一一处我们主动牺牲便利的地方——中间人风险不能用一个复选框换掉。

落点规则是配置项，不是猜测

编译落哪台、采集落哪台写在“默认落点”里且可改。性能采集默认单独指到压测机——和编译共机会让采集数据失真，这条不该靠用户自己想到。

本机能做的不阻断

本机非鲲鹏时，源码扫描与静态分析照常在本地跑，只有交叉编译与性能采集需要远端。不因为“环境不对”把整个产品锁死。

连通性影响渲染

探测到 SSH 低带宽时整体切到低重绘档。连接质量是渲染策略的输入，不是只拿来显示的一个数字。

分类切到「账号」

账号页承载凭据，所以它同时是错误体系与凭据纪律的样板屏：上次验证失败按“发生了什么 → 为什么 → 怎么解决”三段展开，并额外给出影响面——令牌过期不会让 Agent 停摆，但会让改动失去案例库证据，屏 3 的证据区随之显示为不可用。用户需要据此决定现在处理还是先干活。
